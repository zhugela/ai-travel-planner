# 技术债追踪

> 技术债不是待办池。每项必须有风险、触发条件、验收条件和当前状态。

| ID | 优先级 | 债务 | 风险 | 触发/下一步 | 状态 |
|---|---|---|---|---|---|
| TD-01 | P0 | 文件类工具未统一安全路径解析 | 路径穿越、任意文件读写 | 先补越界测试，再接统一 resolver | open |
| TD-02 | P0 | 终端工具通过 shell 解释整段字符串 | 命令连接符、重定向、子命令绕过 | 默认不注册或改结构化沙箱工具 | open |
| TD-03 | P1 | 抓取/下载缺少完整 SSRF 与大小限制 | 内网探测、资源耗尽 | 增加 URL/IP/重定向/响应体测试 | open |
| TD-04 | P1 | 测试基线存在红灯 | 完成声明不可信 | 2026-11-12 已运行：100 tests / 45 errors；先补 ChatModel 测试占位 | active |
| TD-05 | P1 | 接口无鉴权、归属、限流 | 费用与隐私风险 | 生产化前设计身份和配额 | open |
| TD-06 | P1 | 检索前置判空和 Advisor 可能重复检索 | 延迟和成本增加 | 增加耗时/命中观测后合并链路 | open |
| TD-07 | P2 | 需求、测试文档与代码状态漂移 | Agent 选错任务或写假 passing | 按代码和证据重新核对 | open |
| TD-08 | P2 | 缺少 traceId 和工具审计 | 故障难关联、安全事件难追查 | 增加 requestId、工具耗时和状态指标 | open |
| TD-09 | P2 | Docker 与前端 E2E 无当前证据 | 演示环境风险 | 基线转绿后做冒烟 | open |
