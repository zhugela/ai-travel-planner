# Agent 高风险工具安全

> 状态:部分采用
> 来源:Agent 工具代码审查
> 最后验证:2026-11-10

## 问题

普通聊天只生成文本,工具型 Agent 会把模型决定变成真实操作。Prompt 注入、模型误判或参数校验缺陷可能触发命令执行、任意文件访问、内网探测和大文件下载。

核心原则:**模型可以提出操作意图,但不能直接决定系统权限边界。**

## 风险分级

| 等级 | 例子 | 默认策略 |
|---|---|---|
| 低 | 时间换算、纯计算、只读固定数据 | 可默认启用,仍限制输入大小 |
| 中 | 公网搜索、天气查询 | 依赖健康检查、超时、频率限制 |
| 高 | 文件写入、网页抓取、下载、发消息 | 默认受限,校验目标与权限,完整审计 |
| 极高 | 通用终端、删除、部署、付款 | 默认关闭;优先改为专用工具或沙箱 + 人工确认 |

## 可复用规则

### 1. 注册时做能力门控

- 配置缺失、依赖不可用或环境不允许时,不要把工具注册给模型。
- Prompt 中说明不可用能力只是体验优化,不是安全边界。
- 开发与生产使用不同工具清单。

### 2. 通用终端不靠字符串白名单保护

`cmd /c`、`bash -c` 会解释连接符、重定向、变量、子命令和脚本参数。只检查第一个单词不能证明整条命令安全。

推荐顺序:
1. 优先删除通用终端,为明确任务提供结构化专用工具。
2. 必须保留时,使用隔离账户、固定工作目录、无网络沙箱、资源上限和短超时。
3. 参数采用结构化数组,不要把整段字符串交给 shell 解释器。
4. 高影响动作增加人工确认,并把确认范围绑定到具体参数。

### 3. 网络工具防 SSRF 与资源耗尽

- 只允许 `http/https`,解析后的每个目标 IP 都要检查。
- 拒绝 loopback、链路本地、私网、云元数据地址和非预期端口。
- 每次重定向重新校验目标,限制重定向次数。
- 限制连接/读取超时、最大响应体、MIME 类型和落盘大小。
- 生产环境可采用域名允许列表或受控代理。

### 4. 工具输出也不可信

- 限制输出长度,避免 Prompt 和日志膨胀。
- 网页、文件和第三方返回内容可能含提示注入,不能提升其指令优先级。
- 面向用户展示前进行 HTML/Markdown 安全处理。

### 5. 审计但不泄密

记录请求 ID、用户/服务身份、工具名、目标摘要、耗时、结果状态和拒绝原因;不要记录密钥、完整隐私数据和无限长正文。

## 验收清单

- [ ] 生产默认工具清单中没有通用终端。
- [ ] 不可用工具不会注册给模型。
- [ ] shell 连接符、重定向、子命令和脚本文件绕过均被测试。
- [ ] 网络工具拒绝 `127.0.0.1`、私网、元数据地址与恶意重定向。
- [ ] 文件工具通过统一安全路径解析器。
- [ ] 所有外部调用有超时、大小和频率上限。
- [ ] 高影响动作有身份校验和必要的人工确认。
- [ ] 工具调用能按 requestId 审计,日志经过脱敏。

## 本项目现状

已采用:
- WebSearchTool 按依赖可用性进行注册门控。
- 工具输出有部分长度限制,Agent 每次请求新建实例。

待处理:
- TerminalTool 仍注册给模型,并通过 shell 解释整段命令。
- 网页抓取和下载缺少完整 SSRF、响应大小、超时和重定向控制。
- 文件类工具需要统一安全路径边界。
- 接口尚需鉴权、限流与工具级权限控制。
