# 新用户首次使用

## 1. 目标

首次打开页面的用户无需阅读教程，就能知道系统能做什么，并在 1 分钟内完成第一次
有效请求。

## 2. 首屏

首屏需要展示：

- 产品名：AI 旅行规划助手。
- 一句价值说明：把旅行需求整理成可执行行程。
- 四个明确入口：旅行问答、智能行程、灵感探索、旅行工具。
- 示例问题，不自动消耗模型额度。
- 当前网络/服务异常时的可读提示。

首屏不展示内部模型名、API Key、SSE 实现或调试信息。

## 3. 核心引导

### 路径 A：快速问答

1. 用户点击“北京 3 月适合穿什么？”。
2. 输入框填入问题但不自动发送。
3. 用户确认发送，看到逐块输出。
4. 流结束按钮复位，保留 `conversationId` 供续聊。

### 路径 B：生成行程

1. 用户输入目的地、天数、人数、预算和节奏。
2. 信息缺失时系统在 `assumptions` 中写明默认值。
3. 页面显示逐日卡片、预算拆分和注意事项。

### 路径 C：知识库问答

1. 用户输入攻略类问题。
2. 命中时显示回答；未命中时显示固定兜底。
3. 未命中不得伪装成正常答案。

### 路径 D：Agent 工具任务

1. 用户提交需要工具的任务。
2. 页面展示步骤流和工具结果。
3. 完成后按钮复位；失败或循环时展示明确状态。
4. 用户离开页面时连接关闭。

## 4. 空态与错误态

| 场景 | 期望 |
|---|---|
| 空输入 | 阻止发送并提示补充内容 |
| 超长输入 | 前端限制或明确提示，不直接压垮后端 |
| 网络失败 | 显示重试提示，不重复自动发送 |
| RAG 未命中 | 显示“暂无相关攻略”，不是空白或编造 |
| Agent 超时 | 显示可重试或缩小任务范围的建议 |
| 报告字段缺失 | 页面局部空态，不白屏 |

## 5. 验收

- [ ] 首次访问 10 秒内理解四个入口。
- [ ] 每条示例路径都能进入对应页面。
- [ ] 空输入、网络失败、RAG 未命中均有可读反馈。
- [ ] 浏览器 Console 无阻断错误。
- [ ] 375px 宽度可用。
- [ ] 页面卸载时所有 EventSource 已关闭。

## 6. 当前实现边界

- 没有登录和用户资料。
- 示例问题不会根据个人历史推荐。
- 前端仓库不在当前后端仓库。
- 多模态上传未交付。
